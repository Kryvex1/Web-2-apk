# Web-2-apk

A native Android application built with Kotlin and Jetpack Compose designed to package web applications into production-ready Android APKs through an automated, guided workflow.

Web-2-apk streamlines web-to-mobile packaging by handling manifest generation, asset integration, hardware permissions, branding configurations, and packaging pipelines directly within an Android environment.
